Fruity Password

Generate passwords and passphrases.

Works entirely offline. Fruity Password generates credentials on this device and sends zero data to any server.

How to use

  1. Choose Password or Passphrase and adjust the generation options.
  2. Select Generate. To customize a password, edit it directly while it’s visible.
  3. Select Copy to put the result on the clipboard, or Clear to remove it from the current tab.

Each tab keeps its latest result in memory while the app is open. Clipboard history, synchronization, and other applications may retain anything you copy.

Estimated randomness and character sets

Estimated randomness describes how many equally likely results your settings allow. One bit means two possibilities, like the two sides of a fair coin. Each additional bit doubles the number of possibilities, so 10 bits means 1,024 possible results.

For generated passwords, the estimate counts results that include every selected character class. Editing a password clears its estimate. For passphrases, it uses the chosen word count and the size of the bundled word list. Guessing time also depends on how and where the credential is used.

A few words on the list contain a hyphen. Each counts as one word.
